# Changelog

All notable changes to Dusa Boosting, newest first. Download the latest version from [CFX Portal → Granted Assets](https://portal.cfx.re/assets/granted-assets).

### 1.0.0

_October 22, 2026_

* Added the first public release of Dusa Boosting: tablet contracts from class D to S+, solo or group boosts, tracker hacks and VIN scratching.
* Added the Boost Coin store and a player contract market for trading contracts.
* Added signature S+ vehicles protected by a lock that needs a digiscanner hot/cold scan and a pickpocket step.
* Added an optional Chop Shop outcome for finished contracts when Dusa Chop Shop is installed.
* Added ESX, QBCore and Qbox support through Dusa Bridge, plus a migration command for servers moving from rahe-boosting.
